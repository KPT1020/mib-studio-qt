Title: Cap preview display to 60 Hz (configurable)

Context
- Requirement: Smooth UI preview at 60 Hz, keeping camera capture at full rate.
- Followed ready-made patterns and used spdlog for logging per workspace rules.

Changes
- Added `display_fps` to `resources/defaults/config.json` (default 60).
- Updated `src/frontend/PlaybackPanel.cpp` to read `:/defaults/config.json` and set the refresh `QTimer` using `Qt::PreciseTimer` with interval derived from `display_fps`. Clamped to [1, 240].
- Log line on startup: `Playback preview: display_fps=<n> (~<ms> ms)`.
- Display metrics (already present) continue to report actual display FPS.

Impact
- Preview UI refreshes at configured rate (default 60 Hz). Capture, processing, and metrics unchanged.

Notes
- Use `windeployqt` for Release deployment as usual. No additional runtime deps.
